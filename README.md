# 🌍 Global Observer | NASA EONET 3D Engine

**Global Observer** is a *high-fidelity 3D spatial engine* that maps **real-time NASA ecological data** onto an interactive, glass-morphic Earth to track global natural events with surgical precision.

---

## 🚀 Core Features

*   **Dynamic Orbital Beacons**: High-intensity light beams that project from event sites into deep space, *color-synchronized* to match the event category (e.g., **Red for Wildfires**, **Blue for Storms**).
*   **Intelligent Location HUD**: A custom-built, glass-morphic search system with alias support for common names like *USA*, *UK*, or *America*.
*   **Real-time Surface Telemetry**: Live **Latitude/Longitude** coordinate tracking that updates instantly as the cursor explores the planetary surface.
*   **NASA EONET Integration**: Native data streams for *Wildfires*, *Severe Storms*, *Volcanoes*, *Floods*, and more, fetched directly from NASA’s archives.
*   **Temporal Navigation**: A specialized timeline engine allowing users to explore the last **365 days** of Earth’s history with a dedicated *Auto-Playback* mode.
*   **Enhanced Data Streams**: Enlarged, high-visibility source links for deep-diving into the scientific origins of every detected event.

## 🛠️ Technical Stack

*   **Engine**: *Three.js* (WebGL) for 3D rendering and planetary physics.
*   **Animation**: *GSAP (GreenSock)* for surgical camera transitions and orbital focus.
*   **Styling**: *Tailwind CSS* for a modern, responsive "NASA-style" HUD.
*   **Data Source**: *NASA EONET API (v3)* providing live planetary event streams.
